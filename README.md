# Maze Forge · 迷宫锻造

单文件 HTML 工具：生成**完美迷宫**（Perfect Maze），并对任意起点/终点做**寻路可视化**。
零依赖、完全离线，打开 `index.html` 即用。

> 一个「完美迷宫」= 任意两格之间**恰好一条**通路：无环、无孤格、处处可达。
> Maze Forge 用三种经典算法生成，并用自带求解器验证「完美性」后再上屏。

## 特性

- **三种生成算法**
  - `递归回溯 Recursive Backtracker`（栈式 DFS）— 长走廊、深分支
  - `随机 Prim`（frontier 集合）— 短分支、更「均匀」的树
  - `随机 Kruskal`（并查集 + 边洗牌）— 统计上最均匀
- **三种求解器**
  - `BFS` 广度优先 — 最短路径（~ 步数最少）
  - `A*` 曼哈顿启发式（二叉最小堆）— 最短路径，扩展更少
  - `DFS` 深度优先 — 任意一条通路
- **种子可复现**：同一 `(规模, 算法, 种子)` 永远得到同一迷宫
- **正确性自检**：生成后自动断言「完全连通 + 恰好 N−1 条通路」才渲染
- **交互可视化**：墙/通路/访问填充/寻路轨迹分色显示；一键下载 PNG
- **引擎与界面分离**：纯算法引擎挂在 `globalThis.MAZE`，无 DOM 依赖，可单独测试

## 快速开始

直接双击 `index.html`（或拖进浏览器）。

1. 选规模（11×11 / 15×15 / 25×25 / 41×41）
2. 选生成算法 + 填种子（留空随机）
3. `生成` → 画布出迷宫（左上 S，右下 E）
4. `求解` → 选 BFS / A* / DFS 画出通路
5. `重置` / `下载 PNG`

## 算法与正确性

迷宫用 4-bit 每格编码墙：`N=1, E=2, S=4, W=8`（初始全墙 = 15）。
`carve` 打通相邻两格共享的墙。

**完美迷宫不变量**（生成后强制校验）：
- 从 0 出发 BFS 可达格数 `=== R*C`（完全连通）
- 开放边数 `=== R*C − 1`（恰好 N−1 条，即一棵树）

求解器返回的通路再经 `validatePath` 做逐步邻接校验，确保每一步都是真实打通的墙。

## 技术栈

- 纯原生 HTML + CSS + JS（`<canvas>` 绘制），无任何外部库 / 网络请求
- 引擎脚本 `<script id="engine">` 暴露 `globalThis.MAZE`
- 测试：`_smoke.js`（Node + `vm` 沙箱）43 项断言全绿；`_probe.js` 输出 ASCII 迷宫供肉眼检查

```bash
node _smoke.js   # 引擎断言（确定性 / 完美性 / 求解有效性 / 边界）
node _probe.js   # ASCII 探针：渲染小迷宫 + 通路
```
